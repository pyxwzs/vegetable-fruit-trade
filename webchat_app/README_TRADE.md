# 果蔬批发 · 微信小程序

基于 TDesign 小程序模板（`webchat_app`）重构的租户端，对接现有 Spring Boot 后端。

## 角色划分

| 角色 | 入口 |
|------|------|
| 租户用户 | 本小程序（登录 / 邀请码注册） |
| 平台管理员 | Web **`/platform/login`**（租户管理、邀请码，不使用小程序） |

## 本地开发

1. 安装依赖（项目根目录 `webchat_app`）：

```bash
cd webchat_app
npm install
```

2. 微信开发者工具 → 导入本项目 → AppID 使用你的小程序 AppID（已配置 `wx547f5abb5ec6b5a7`）。

3. 修改 `config.js` 中的 `baseUrl`：
   - 模拟器：`http://127.0.0.1:8080/api`
   - 真机调试：改为电脑局域网 IP，如 `http://192.168.1.10:8080/api`

4. 开发者工具 → **详情 → 本地设置 → 不校验合法域名**（开发阶段必开）。

5. 启动后端（端口 8080，context-path `/api`）。

6. 开发者工具 → **工具 → 构建 npm**（使用 `tdesign-miniprogram` 组件）。

## 功能结构

- **首页**：月度应赚/实赚、往来库存、待入库/待出库待办（对齐 Web 仪表盘）
- **业务**：采购、销售、商品、库存、供应商、客户、支出、对账
- **采购/销售**：列表筛选 + 详情 + 入库/出库 + 登记收付款
- **我的**：个人资料、修改密码、退出登录

## 平台管理 Web

浏览器访问：

- 登录：`http://localhost:8081/platform/login`（按 frontend 实际端口）
- 租户管理：`/platform/tenants`

默认平台管理员：`admin` / `admin123`
